# justamanda.net — Books Series Reference

**Purpose:** Working reference for the Books section of justamanda.net  
**Updated:** September 3, 2026

This file consolidates the book series Amanda has named during Books-page curation, with title, series, and author information.

## Scope notes

- **Twilight:** only the four main Bella-narrated novels are included. Amanda did **not** read the spin-offs / companion novels.
- **The Hunger Games:** only the original Katniss trilogy is included. Amanda did **not** read the later prequel novels.
- **Fifty Shades:** only the original trilogy is included here. The Christian-POV retellings are omitted because they were not identified as part of Amanda's reading history.
- **Shadowhunters:** Amanda named the Shadowhunter books and confirmed recognition of the *Clockwork* books, so this file includes **The Mortal Instruments** and **The Infernal Devices**. Later Shadowhunter subseries are not marked as part of her reading history unless she confirms them separately.
- For current series that are still publishing, currently released books are included. Newly announced/unread titles are called out separately where useful so they are not confused with Amanda's confirmed reading history.
